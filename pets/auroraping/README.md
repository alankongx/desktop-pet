# 极光萌可桌宠（auroraping-pet）

《奇妙萌可》极光萌可桌面桌宠，与大圣派特（dasheng-pet）同架构：Electron 透明无边框悬浮窗。

## 启动

```bash
cd /Users/alankongx/WorkBuddy/2026-08-15-22-55-17/desktop-pet
./launch.sh        # 或 node start.js
```

依赖通过符号链接复用大圣派特的 node_modules：
`node_modules -> /Users/alankongx/WorkBuddy/2026-08-04-23-23-24/desktop-pets/official-pet/node_modules`
（若该目录被清理，进入本目录执行 `npm install` 后即可独立运行）

## 尺寸说明

三档尺寸都按**统一高度**缩放，保证带翅膀的萌可和不带翅膀的萌可身高一致：

| 档位 | 窗口尺寸（宽×高） | 角色高度 | 窗口宽度依据 |
| --- | --- | --- | --- |
| 小 | 148 × 156 px | 96 px | 容纳展翅姿态 fly.png 的宽度 |
| 中 | 192 × 218 px | 128 px | 容纳展翅姿态 fly.png 的宽度 |
| 大 | 286 × 332 px | 192 px | 容纳展翅姿态 fly.png 的宽度 |

## 交互

| 操作 | 效果 |
| --- | --- |
| 按住拖动 | 移动位置（不会误触发言语） |
| 单击 | 随机发言（赴约 / 极光绽放 / 翱翔 / 加油） |
| 双击 | 「极光，绽放！」↔「恢复平静」 |
| 三击 | 回星星村 5 秒 → 回归 |
| 右键 | 尺寸（小/中/大）+ 永远退出 |
| 待机 40~80 秒 | 随机情绪：思考/开心/翱翔/生气/睡觉 |

## 文件结构

- `main.js` 主进程：透明置顶窗、拖动 IPC、右键菜单、尺寸持久化（config.json）
- `preload.js` 渲染 ↔ 主进程桥
- `renderer/` 界面 + 4 态状态机 + 台词
- `images/` 原始 4 张 JPG；`assets/` 抠图后透明 PNG

台词按极光萌可人设编写：代表元素「承诺」、金色弓箭、极光魔法、守护宇宙星星村、与王子萌可跨年庆典一年一见的约定。
