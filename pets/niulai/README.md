# 牛来桌宠

Q版金牛宝宝桌面宠物，金棕色圆胖身体、小金角、红围巾（中国股市红涨配色），代表"希望牛市早点来"。

## 7 个状态

| 状态 | 图片 | 说明 |
|---|---|---|
| 暗中 | `assets/anzhong.png` | 暗中观察（默认状态） |
| 上头了 | `assets/shangtou.png` | FOMO 上头，冲动加仓 |
| 摆烂 | `assets/bailan.png` | 躺平不看盘，等牛自己来 |
| 无语 | `assets/wuyu.png` | 被行情整无语了 |
| 开摆 | `assets/kaibai.png` | 满仓红，收盘去消费 |
| 发疯 | `assets/fafeng.png` | 牛市真来了，疯了疯了 |
| 你说的 | `assets/nishuode.png` | 你说的都对，但我还是要满仓 |

## 交互

- **拖动**：按住宠物任意位置拖拽移位
- **单击**：随机切到 7 态之一，并说对应台词
- **双击**：循环切换到下一个状态
- **三击**：先摆烂 5 秒，然后发疯回归
- **右键菜单**：切换小/中/大三种尺寸、完全退出
- **待机**：40~80 秒随机触发一个小剧场

## 台词原则

牛来是吉祥物，台词永不出现"亏/赔/完/割肉"等晦气词。即便摆烂、无语也用幽默乐观的方式表达——牛永远在路上。

## 启动

```bash
./launch.sh
```
